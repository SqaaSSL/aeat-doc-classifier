**Two known scanned form identities recovered; one newly accepted.** This comparison uses five extraction cases from the already inspected public-v1 corpus. It is a development regression, not independent validation and not a rerun of all 44 pages. The original baseline remains unchanged.

LiteParse 2.14.6 with Spanish (`spa`) ran locally; Jev was pinned to `jev-1.13.0`. Both classifier conditions used isolated pages and the existing 0.95 confidence/probability gates. No context retries, threshold changes, filename hints or gold labels were supplied to the classifier.

The original native text was 100 UTF-8 bytes on each scanned annex. The OCR input contained 8,342 and 5,991 bytes respectively, including the actual form content. This is evidence of extraction recovery, not a character-error-rate measurement: OCR errors remain, including spacing in model 131's printed identifier. Model 200/206 pages are compatibility probes; the raw run's `expectedForm: null` on these probes is **not a gold claim that no form is visible after OCR**. Only the two pre-identified scanned annexes are used in the recognition denominator above.

There were two completed classifier calls in the Poppler condition and three completed plus one failed call in the LiteParse condition. Completed calls reported 6,586 input / 1,208 output tokens and 12,938 input / 1,833 output tokens respectively. Failed-call usage is unavailable, so these are not complete billing totals. No paid-model call is made for empty input. The failed call was stored as `classification_failed`; its exact cause was not retained and is not asserted here. It remains in the five-probe denominator rather than counting as a successful abstention.

Four whole PDFs were OCR-extracted in about 10.1 seconds combined on this development machine, including the 14-page BOE PDF. Extraction time repeated beside its two selected pages in the raw data refers to the **same single document extraction**, not two independent timings. This is not a portable speed benchmark.

## Reproduce

From a source checkout with dependencies installed, Poppler available and `TYPESAFE_API_KEY` set:

```sh
npm run eval:public -- --download-only
npm run eval:ocr
```

The runner verifies the existing source hashes and native-input hashes, extracts complete documents before inference, then saves a timestamped result under ignored `eval/results/`. A classification error produces a nonzero exit and remains in the saved report. Hosted outputs and timings may vary. This release's first run exited nonzero because the model 206 probe failed classification; it was not replaced with a more favorable rerun.
