# Data and provenance

The original code, manually authored decision descriptions, catalog structure and synthetic evaluation fixtures in this repository are MIT licensed. They use factual model identifiers, account numbers and official labels drawn from the linked AEAT and BOE references. Each catalog record carries its sources and each catalog has a review/version date.

Official source documents are not republished under this project's MIT license. The optional public PDF smoke test downloads AEAT material into the ignored `eval/corpus/` directory and records source URLs and file hashes. Consult the source sites' terms for reuse beyond this project. Synthetic examples are invented and are not genuine returns or filing receipts.

The upstream `kyotofin/tax-doc-classifier` is Apache-2.0 and is acknowledged as architectural inspiration. This project does not contain upstream source files, IRS criteria or benchmark data, and does not relicense them. Any future contribution copying third-party implementation must preserve its applicable license and notices.
